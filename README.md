# Adem Can Demirci - Personal Portfolio

Welcome to the source code of my personal portfolio website! This project is a modern, highly interactive, and fully responsive web application built to showcase my journey, projects, and skills as a Computer Engineering student and Software Developer.

## 🚀 Features

* **Liquid Glass Design System:** A futuristic aesthetic featuring dynamic glassmorphism (`backdrop-filter`), glowing neon accents, and deep translucent layers.
* **Bilingual Support:** Fully accessible in both English (`index.html`) and Turkish (`index-tr.html`).
* **High-Performance Parallax Engine:** Custom Vanilla JavaScript physics for 3D card tilts, floating background blobs, and magnetic buttons, fully hardware-accelerated for 60+ FPS rendering.
* **Dark & Light Modes:** Seamless theme switching controlled via CSS variables and `localStorage` to remember user preference.
* **Interactive Timeline:** A dedicated "My Journey" section structured with alternating cards that dynamically fade up via Intersection Observer.
* **Custom Magnetic Cursor:** A smooth, custom cursor that magnetically attaches to interactive elements (buttons, links, cards).

## 🛠️ Technology Stack

* **HTML5:** Semantic markup and modern structure.
* **CSS3:** Advanced styling using CSS Variables, Flexbox, CSS Grid, animations, and pseudo-elements. No external CSS frameworks were used (Tailwind/Bootstrap free).
* **Vanilla JavaScript:** Custom physics, DOM manipulation, custom typing effects, and high-performance intersection observers.
* **Phosphor Icons:** Minimalist and scalable SVG icons.

## 📁 File Structure

* `index.html` - English version of the portfolio.
* `index-tr.html` - Turkish version of the portfolio.
* `style.css` - Contains the entire design system, layout rules, and liquid glass theme variables.
* `script.js` - Houses all interactions, custom 3D math, cursor logic, and the animation loop.

## ⚙️ How to Run Locally

Since this is a static site, no build steps or heavy servers are required.

1. Clone or download this repository.
2. Open `index.html` or `index-tr.html` directly in your favorite modern web browser.
3. *Optional:* If you want to test locally over a server, you can use VS Code's Live Server extension or run a simple Python server:
   ```bash
   python3 -m http.server 8000
   ```
